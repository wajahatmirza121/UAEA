The `app/main.py` FastAPI entrypoint is the single wiring point: it loads centralized settings from `app.config.Settings`, mounts three domain routers (`chat`, `lookup`, `admin`), installs global middleware (CORS, SlowAPI per-IP rate limiter, session-rate-limit placeholder), and exposes a `/health` endpoint. Cross-cutting concerns are shared through module-level singletons — `settings` for all config, `db.session` for async SQLAlchemy sessions consumed by `db.models`, and the `adapters` package (base + mock) used by the `orchestrator` to call external LLM/embedding providers. The `orchestrator` layer sits between API handlers and the `rag` ingest/retrieve subsystem, routing intents and enforcing guardrails before invoking tools. Database schema migrations live under `alembic/versions` driven by `alembic.ini`, and seed data is provided via `db.seed`. Tests in `tests/` mirror the app's package layout and use `conftest.py` fixtures to share DB/session setup across chat, guardrails, lookup, and RAG retrieval scenarios.
