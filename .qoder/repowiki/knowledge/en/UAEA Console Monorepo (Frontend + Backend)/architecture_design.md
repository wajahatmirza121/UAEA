The repository is split into two sibling services: `frontend/` (Vite + React SPA) and `backend/` (FastAPI). They are currently decoupled — the frontend runs entirely off local mocks (`src/mocks/*`) and does not call the backend. The README documents a single integration point: every write goes through `mutate(table, id, patch, meta)` in `src/context/AppContext.jsx`, which will be swapped to POST/PATCH/DELETE `/v1/admin/content/{table}` against the backend once wired. Role-based UI permissions in `src/lib/rbac.js` mirror the intended server-side middleware contract, so both sides share the same permission model at the boundary.
